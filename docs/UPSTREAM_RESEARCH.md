# 上游项目调研记录

调研日期以本仓库 Git 历史为准。本文件只记录公开资料，不表示接口仍然可用。

## 公开项目

- `321CQU/321CQU`：功能和微服务架构文档，AGPL-3.0。
- `321CQU/API_Gateway`：旧/新 API 网关，AGPL-3.0。
- `321CQU/pymycqu`：重庆大学统一认证和校园服务 Python 封装，AGPL-3.0。
- `321CQU/rsmycqu`：对应 Rust 封装，AGPL-3.0。
- `321CQU/Old_Backend`：已归档旧后端。
- `ChenJiaming5613/321CQU_mini`：旧微信客户端，AGPL-3.0。

## 已知功能面

公开代码曾覆盖：课表、选课、考试、成绩、GPA/排名、课程历史成绩、空教室、校园卡、宿舍费用、图书借阅、志愿时长和体测等。

`pymycqu` 公共代码中可见的旧 `my.cqu.edu.cn` API 类别包括：

- 学期与资源信息；
- 学生课表与选课；
- 考试安排；
- 学生成绩与 GPA 排名。

这些 URL 只能作为待验证线索，不能当作新版系统的稳定公开协议。

## 不能直接移植的内容

旧小程序代码中出现过第三方共享 API key，并把统一认证密码保存在客户端存储后交给第三方 API 登录。新版不采用这种设计，也不携带任何第三方服务凭据。考试查询所需的固定 AES参数是学校前端协议的一部分，不具有认证能力；请求仍只能在当前用户已经手动建立的官方会话内访问本人数据。

当前 Android 客户端的 UI、缓存和网络层均以 Kotlin 独立实现，没有复制微信小程序源文件。部分官方接口路径、字段结构和考试参数协议常量在验证学校前端行为时参考了上述 AGPL 项目；因此本项目整体采用 `AGPL-3.0-only`，并保留本调研与来源记录。后续若直接复用更多上游代码，必须补充逐文件版权和修改说明。

## 课程口碑与历史成绩

该类信息不是普通个人查询：它需要跨用户聚合或合法公共数据源。正式实现前必须确认来源和学校规则；只显示达到最低样本量的去标识汇总，不提供个人记录，不允许通过筛选反推出个体。
