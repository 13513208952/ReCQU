# 校园网验证清单

在需要访问教务系统时再执行本阶段。只使用测试者本人的账号和有权查看的数据。

## 用户需要准备

1. 切换到重庆大学校园网，或使用学校认可的 VPN。
2. 准备 Android 真机，系统版本尽量覆盖 Android 10、13、15/16。
3. 确认浏览器能正常打开新版统一身份认证和教务系统。
4. 不要把账号密码发送到聊天、终端历史、截图、HAR 或 Git。

## 第一次验证步骤

1. 记录入口 URL、最终域名和公开页面版本号。
2. 用浏览器开发者工具观察**本人正常操作**产生的请求：登录跳转、学期、课表、考试、成绩。
3. HAR 导出前删除 `Cookie`、`Authorization`、学号、姓名、成绩等内容；脱敏文件放在被 `.gitignore` 的 `captures/` 中。
4. 确认请求方法、参数、返回字段、分页、错误码和会话过期行为。
5. 若出现验证码或手机二次认证，立即暂停，由用户在官方页面手动完成；不自动识别、不代收、不绕过。
6. 以低频单次请求编写契约样例和解析测试，不扫描、不批量枚举。

## 首轮只验证

- SSO 正常登录与退出；
- 当前学期及学期列表；
- 本人课表；
- 本人考试安排；
- 本人成绩。

空教室、他人课表、课程历史分布、校园卡和图书馆放到后续独立评估，避免一次扩大访问范围。

## 禁止提交

- 真实密码、Cookie、Token、验证码；
- 未脱敏 HAR/PCAP；
- 真实学号、姓名、成绩和座位；
- 学校私钥、第三方 API key 或任何具有认证能力的共享凭据；
- 可用于绕过权限或批量抓取的脚本。
