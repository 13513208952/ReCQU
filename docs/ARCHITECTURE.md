# 架构设计

## 目标

将频繁变化的校园服务接口与稳定的 Android 界面解耦，并避免旧版“客户端保存明文密码、共享密钥写入源码、所有数据经过第三方服务器”的风险。

## 模块（当前单 module，按 package 分层）

```text
ui/                  Compose 页面、状态与 ViewModel
     ↓
domain/              稳定领域模型与 CampusRepository 接口
     ↑
data/                Demo 数据；后续增加 official/ 与 local/
```

后续真实数据链路：

```text
Compose UI
  → ViewModel
  → CampusRepository
      → OfficialCampusAdapter（官方 HTTPS API）
      → LocalCache（仅缓存必要字段）
      → AggregateAdapter（可选；仅匿名汇总公开数据）
```

## 身份认证方案

使用受限 WebView 打开学校官方 SSO 页面，由用户直接在官方页面完成密码和手机验证码认证。应用不读取登录表单，不把密码或验证码发给项目服务器。

新版系统带有浏览器动态防护，因此接口请求通过已认证的 `my.cqu.edu.cn` 页面执行同源 `fetch`。Cookie 和 OAuth Token 留在 WebView 存储中，不提取到 Kotlin；原生层只接收本人业务接口的响应。退出时清除 LocalStorage、SessionStorage、Cookie 和 WebView 缓存。认证 WebView 的顶层导航限制为 `my.cqu.edu.cn` 与 `sso.cqu.edu.cn`；官方页面的 HTTPS 子资源与子框架按标准浏览器行为加载，不维护易失效的资源域名白名单。仅两个校园域名通过应用内、端到端 TLS 的 CONNECT 路由解决局部 DNS 异常，其余资源直接联网。

## 数据分类

| 等级 | 示例 | 策略 |
|---|---|---|
| 高敏感 | 密码、Cookie、访问令牌 | 不写日志；Android Keystore；退出立即删除 |
| 个人数据 | 学号、课表、成绩、考试座位 | 默认仅本地；禁用云备份；可一键清除 |
| 聚合数据 | 课程历史分布、教师课程口碑 | 设最小样本量；去标识；明确来源与更新时间 |
| 公共数据 | 校历、楼栋、班车 | 可缓存，保留来源 |

课表与成绩分别写入应用私有目录中的 `AtomicFile` 快照。冷启动先展示与当前用户匹配的完整快照，再尝试独立刷新；网络错误、会话失效、响应缺少列表或解析数量不一致时保留旧快照。成绩刷新不依赖考试接口成功，空响应也不会覆盖同一用户已有的非空成绩。

桌面小组件采用标准 Android `AppWidgetProvider` 和 `RemoteViews`，面向所有实现标准 App Widget 协议的 Android 桌面，提供“下一节课”和“今日课程”两种核心组件；小米澎湃 OS 只是当前真机验证平台，不使用任何厂商私有能力。组件只读完整课表快照，不自行联网或发起 WebView 认证；课表成功写入、开学日期修改、缓存清除、应用每次进入前台以及系统日期/时间变化时重新渲染。两个组件共享同一次时间快照，任一 Provider 收到桌面周期回调时都会同步刷新全部课表组件，避免各 Provider 的桌面调度不一致导致“下一节课”停留在旧状态。未添加组件时不运行额外更新任务，应用内也不展示添加入口；快捷固定代码暂时保留，但由于多个国内厂商桌面会接收后立即取消标准 `requestPinAppWidget()` 请求，其 UI 入口默认关闭。用户通过系统桌面的小组件选择器手动添加。组件会根据标准桌面传入的可用尺寸与系统字体缩放自动降低信息密度：今日课程始终显示至少 2 条、通常显示 4 条剩余课程；下一节课在空间不足时优先隐藏教师和完整时段等低优先级文本。

## 兼容策略

- `minSdk 29`：Android 10。
- `targetSdk/compileSdk 36`：Android 16。
- 使用 Java 17、Kotlin、Compose Material 3。
- 禁止 cleartext HTTP；若某校内旧服务只支持 HTTP，应推动 HTTPS 或通过明确隔离的可信代理解决，不能全局放开。

## 后端原则

核心个人查询不依赖自建后端。只有通知、跨用户匿名统计等确有必要的功能才考虑后端，并要求：明确知情同意、最小化存储、可删除、频率限制、审计、公开源代码和隐私说明。

旧版所谓“教师评教分数”实际来自跨用户汇总的课程成绩均分和分布，并非学校官方教学评价。新版必须使用准确名称，并在没有合规聚合数据源时保持功能关闭。
